## Part A — House rules

The generator follows these for every question. They come from Modules 1–3.

### A1. Scope

1. Questions are for supervised, invigilated use only.
2. Multiple choice is never the only assessment in a module. Flag any plan that puts more than 30% of the module grade on it.
3. Single best answer only. One correct key per question.

### A2. Levels are defined by the task, not the verb

If the answer was given in the teaching, the question is Remember, whatever verb it uses. Tag every question with a level and a knowledge type (Factual, Conceptual or Procedural).

| Level | What the student must do |
| --- | --- |
| Remember | Retrieve a fact or idea exactly as taught |
| Understand | Explain, classify or compare ideas as taught, in their own terms |
| Apply | Use a taught principle or procedure on a case they have not seen |
| Analyse | Work out relationships in material they have not seen: data, a case, an extract |
| Evaluate | Judge an argument, method or answer against criteria they were taught |

No Create questions. Selected-response formats cannot assess it.

Difficulty and level are separate. A hard recall question is still Remember.

### A3. Writing each question

1. The stem states the whole problem. A student should be able to answer it with the options covered.
2. No material the student does not need.
3. No negatives. If one is unavoidable, put it in **BOLD CAPITALS**.
4. Options agree grammatically with the stem and are similar in length and form.
5. Options do not overlap. Numerical ranges do not touch.
6. No "all of the above" or "none of the above".
7. Spread the key evenly across positions.
8. Each question stands alone. None cues or answers another.
9. Test only what was taught.

### A4. Options and distractors

1. Use three or four options. Plausibility matters more than the count.
2. Every distractor comes from a misconception listed in B3, or a common error a student who half understands would make.
3. Record which misconception each distractor represents.

### A5. Checks to run on every question

For each question, report pass or fail on:

- Level tag and knowledge type present
- Higher-order question uses a case, data or argument not listed in B2
- Exactly one key
- 3–4 options, all similar in length (none more than 1.5× the shortest)
- No "all/none of the above", no unmarked negatives
- Every distractor linked to a misconception
- Distribution across the set matches B4
- Total time fits the paper length in B5
